## Reproduction

With Python >=3.11 and working Tk support installed:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[test]'
.venv/bin/python -m pytest -v -ra --junitxml=baseline.xml
.venv/bin/python -m pip check
.venv/bin/python -m hakimino --help
```

Select a compatible Python executable explicitly if `python3` is older than 3.11.
On Windows use `.venv\Scripts\python.exe`. GUI tests require Tk and a display.
The test XML is a local output; do not commit personal paths or real credentials.
